# リリースノート

## 1.1.0

### 追加

- **レート制限の管理:** System > Rate Limiting でカウンター、履歴、上位の送信元を確認し、IP ブロック、除外、設定を管理できます。
- **自動ブロックと履歴:** 繰り返し制限された IP をブロックし、件数に上限のある時間別履歴を保存します。
- **緊急操作:** 試行制限の一時停止、`RATE_LIMITING_ENABLED` による緊急回避、ロックダウンを備えたサイト全体の IP ごとの上限を追加しました。
- **登録用ハニーポット:** 隠しフィールドを入力する自動登録を拒否します。

### 変更

- 従来の制限処理を、認証とプロフィール SSO のルートに適用する固定ウィンドウ方式の `AppThrottle` ミドルウェアに置き換えました。cbSSO コールバックと慣例に基づく認証 URL も制限します。
- 最小バージョンを ColdBox 8.3 と cbSecurity 3.9 に引き上げ、フレームワークと TestBox のインストール先を修正しました。
- ドキュメントのテーマ、データベース初期化手順、レート制限の説明を更新しました。

### 修正

- 試行回数をアトミックに計上し、各ウィンドウで最初にブロックされたリクエストのみを監査します。
- ログインフォームが制限対象のルートに送信するよう修正しました。
- CI の依存関係インストールとテストレポートを改善しました。

詳細は[レート制限](../guides/security.md#rate-limiting)と[変更履歴](https://github.com/coldbox-templates/cbGenesis/blob/development/changelog.md)を参照してください。
